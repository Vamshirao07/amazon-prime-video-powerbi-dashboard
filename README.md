# Amazon prime video powerbi-dashboard
## 📊 Project Overview

This project presents an interactive *Amazon Prime Video Dashboard* created using Microsoft Power BI.

The dashboard analyzes the Prime Video content catalog and presents key information about titles, ratings, genres, directors, countries, content types, and release years.

## 🎯 Project Objectives

- Analyze the Amazon Prime Video content catalog
- Understand the distribution of Movies and TV Shows
- Analyze content by country
- Identify major genres
- Analyze ratings by total shows
- Understand content trends by release year
- Build an interactive and visually appealing Power BI dashboard

## 📌 Dashboard KPIs

| KPI | Value |
|---|---:|
| Total Titles | 9,651 |
| Total Ratings | 25 |
| Total Genres | 518 |
| Total Directors | 5,769 |
| Start Date | 1920 |
| End Date | 2021 |

## 📈 Dashboard Visualizations

The dashboard includes:

- *Ratings by Total Shows*
- *Genres by Total Shows*
- *Total Shows by Country*
- *Movies vs TV Shows*
- *Total Shows by Release Year*
- KPI cards for key metrics

## 💡 Key Insights

- The dashboard contains *9,651 titles* in total.
- *Movies represent the majority of the catalog*, compared with TV Shows.
- *Drama* is one of the largest genres represented in the dataset.
- The country map shows that content is distributed across multiple regions worldwide.
- The catalog covers content released from *1920 to 2021*.
- The number of titles increases significantly in recent years.
